# Introduction

SkillShare is a handcrafted management platform that allows users to showcase their skills by creating posts. 
Users can engage with their favorite posts by reacting to them, following and unfollowing others,
and building relationships to further enhance their skills.

# Methonologies

SkillShare is a platform with a React-based frontend and a Spring Boot backend, using MySQL as the database. 
Spring Boot is used to establish seamless communication between the frontend and backend.
stablish data transfer between clients and server use Mysql db server as database 

# Features

The SkillShare application offers features like happy, sad, heart, and smart reactions to enhance member collaboration.
It uses OAuth 2.0 techniques for highly reliable security.
A powerful search function helps users easily find individuals among thousands.
Active/inactive status indicators allow members to identify friends' availability for better real-time communication.
